# VTUAN Android V1.3

A standalone VTUAN key activation Android application, not a modified game or in-game menu. Build workflow extracts `app-source.zip` and publishes debug APK as artifact.

Server API: `/api/activate`, `/api/verify` and child server routes. Android SDK 35 / JDK 17 / Gradle 8.9 / Android Gradle Plugin 8.7.3.
